# 사전 공부 (30분)

## 핵심 비유
- **AI 모델** = 공부를 많이 한 학생
- **사전학습** = 학교에서 모든 과목을 배운 것
- **파인튜닝** = 그 학생에게 *특정 과목*(예: 우리 회사 말투)만 과외 시키는 것
- **데이터셋** = 과외 문제집 (질문-정답 쌍)
- **에포크(epoch)** = 문제집을 몇 번 반복해서 풀었는지
- **학습률** = 한 번에 얼마나 크게 고칠지 (너무 크면 헷갈림)
- **과적합** = 문제집 답만 외워서 새 문제는 못 푸는 것
- **LoRA** = 학생 머리 전체를 바꾸지 않고, 작은 메모장만 추가해서 배우는 가벼운 방법
- **토큰** = AI가 글자를 읽는 최소 조각(단어 조각)

## 전체 흐름 (5단계)
데이터 모으기 → 정리하기 → 학습 → 평가 → 사용

1. 파인튜닝은 처음부터 AI를 만드는 것인가? (답: 아니오, 이미 있는 모델을 추가로 가르침)
2. 문제집 답만 외우는 현상은? (답: 과적합)
3. LoRA의 장점은? (답: 빠르고 가볍다)
