# 사전 공부 (1시간) — 중학생 눈높이

## 비유 하나로 끝
AI 모델 = 책을 많이 읽은 학생. 파인튜닝 = 그 학생에게 **특정 과목 과외**.

## 일차별 핵심 용어
### 1일차 — 원리
- **NLP**: 컴퓨터가 사람 말을 다루는 기술
- **토큰**: 글자를 쪼갠 최소 조각 (단어 조각)
- **임베딩**: 단어를 숫자 좌표로 바꾼 것 (비슷한 말 = 가까운 좌표)
- **트랜스포머/어텐션**: 문장에서 "어느 단어를 집중해서 볼지" 정하는 구조
- **사전학습**: 인터넷 글을 엄청 읽으며 "다음 단어 맞히기" 연습
- **LLM**: 아주 크게(파라미터 수십억 개) 키운 언어 모델

### 2일차 — HF · SFT
- **Hugging Face**: AI 모델·데이터 앱스토어 (Hub, transformers, datasets)
- **SFT**: 질문-정답 문제집으로 가르치는 지도 파인튜닝
- **데이터셋**: 문제집 / **에포크**: 문제집 반복 횟수 / **과적합**: 답만 외움

### 3일차 — PEFT · DPO
- **PEFT**: 머리 전체 말고 일부만 고치는 가벼운 학습
- **LoRA**: 작은 메모장(어댑터)만 추가해서 배우기
- **QLoRA**: 모델을 압축(4bit)해서 LoRA — 작은 GPU에서도 가능
- **DPO**: "A답이 B답보다 낫다" 비교 데이터로 답변 취향 맞추기

### 4일차 — 평가 · 서빙
- **평가지표**: 점수 매기기 (Perplexity, BLEU/ROUGE, LLM-as-judge)
- **양자화**: 숫자를 거칠게 줄여 모델을 작고 빠르게
- **추론 최적화**: 답변 속도 높이기 (vLLM, KV캐시, 배치)
- **FastAPI/API**: 내 모델을 웹 주소로 열어 누구나 호출
